# wasm-lang-test 项目规划

## 项目目标

对比 C++、Go、Rust 三种语言在 WebAssembly 中的性能表现，通过四个典型算法测试不同的计算特性。

## 四个测试题目

### 1. 斐波那契数列（递归密集）
- **测试特性**：函数调用开销、栈操作
- **实现**：`fib(n)` 递归计算第 n 个斐波那契数
- **输入**：n = 35
- **指标**：执行时间、内存峰值

### 2. 快速排序（内存操作）
- **测试特性**：内存分配、数组操作、指针操作
- **实现**：随机数组快速排序
- **输入**：100,000 个随机整数
- **指标**：排序时间、内存使用

### 3. 矩阵乘法（计算密集）
- **测试特性**：浮点运算、缓存效率、循环优化
- **实现**：两个 512×512 矩阵相乘
- **输入**：随机浮点矩阵
- **指标**：乘法时间、FLOPS

### 4. 字符串处理（字符串操作）
- **测试特性**：字符串分配、正则表达式、文本处理
- **实现**：统计文本中单词频率（简单版本）
- **输入**：10MB 文本数据
- **指标**：处理时间、内存使用

## 编译策略

### C++ (Emscripten)
```bash
emcripten 编译 → wasm 模块 → npm 包
```

### Go (GOOS=js GOARCH=wasm)
```bash
go build -o main.wasm → wasm 模块 → npm 包
```

### Rust (wasm-pack)
```bash
wasm-pack build → wasm 模块 → npm 包
```

## CI/CD 流程

### 触发条件
- 提交信息包含 `[wasm]` 关键词时触发完整流程
- 自动编译三个 wasm 模块
- 生成 npm 包并发布到 npm registry

### 发布流程
1. **编译阶段**（并行）
   - 编译 C++ → wasm
   - 编译 Go → wasm
   - 编译 Rust → wasm

2. **打包阶段**
   - 生成三个独立 npm 包
   - 版本号从 `package.json` 读取

3. **发布阶段**
   - 发布到 npm registry
   - 同步到 GitHub Packages
   - 生成 Release Notes

### 包名规范
- `@wasm-lang-test/cpp` - C++ 实现
- `@wasm-lang-test/go` - Go 实现
- `@wasm-lang-test/rust` - Rust 实现

## Web UI 功能

### 性能测试页面
- 加载三个 wasm 模块
- 运行四个测试题目
- 实时显示执行时间
- 对比三种语言的性能差异
- 导出测试结果为 JSON/CSV

### 测试指标
- 执行时间（ms）
- 内存使用（MB）
- 相对性能（相对于最快的实现）

## 配置要求

### npm Token 配置
1. 在 npm 官网生成 Automation Token
2. 在 GitHub 仓库 Settings → Secrets → Actions 中添加 `NPM_TOKEN`
3. CI/CD 自动使用该 token 发布包

### GitHub Packages 配置
- 自动同步到 `npm.pkg.github.com`
- 需要 `GITHUB_TOKEN`（自动提供）

## 开发流程

### 本地开发
```bash
# 克隆项目
git clone https://github.com/your-org/wasm-lang-test.git
cd wasm-lang-test

# 安装依赖
npm install

# 编译 wasm 模块
npm run build:wasm

# 启动 UI 开发服务器
npm run dev
```

### 发布流程（仅 wasm 模块）
```bash
# 更新版本号
npm version patch/minor/major

# 提交包含 [wasm] 关键词的 commit
git commit -m "feat: update wasm modules [wasm]"
git push
```

**注意**：UI 不发布到 npm，只在本地开发和 GitHub 上维护
